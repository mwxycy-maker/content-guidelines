# 差评君风格 Skill

从两期样片中提炼（《一通电话的信用，是怎么被230万个骚扰号码毁掉的？》《当"盗版"软件变成零门槛，我们应该高兴吗？》），数值是实测，不是印象。

一句话概括这个风格：**一个人坐在演播间里讲一个社会/科技议题，每说一句话画面就换一个"证据"**。证据包括素材窗里的新闻画面、斜放的官方文件加绿色荧光笔、白底绿柱的数据图、主持人身边弹出的白色纸片图标、漫画插画和 AI 生成的隐喻大场面。全程一条压在人声下 20 dB 的音乐床，几乎没有静音。

## 使用流程

按顺序做，每步读对应的 reference：

1. **选题与口播稿** → `references/script.md`
   产出 3500–4300 字、11–12 分钟的口播稿，按"钩子 → 片头 → 现状数据 → 历史因果 → 反常识 → 另一面 → 落点金句 → 固定结尾"组织。
2. **分镜表** → `references/visual-language.md`，按 `references/storyboard-template.md` 填表
   给每一句字幕（约 2.5 秒一句）指定一种画面类型（A-roll / 素材窗 / 文件 / 数据图 / 叠加图形 / 插画 / 3D / 隐喻大场面），并标出切点。
3. **剪辑节奏** → `references/editing-rhythm.md`
   按段落的目标切速剪。钩子段和列举段要快，论证段放慢。
4. **动效包装** → `references/motion.md`
   十个标志性动效模板，附参数。用 HyperFrames 做的话直接用 `assets/chaping-kit.css` + `assets/chaping-motion.js`（先读 `hyperframes` 和 `hyperframes-animation` skill）。
5. **音乐、音效与混音** → `references/audio.md`
6. **交付前对照** `references/checklist.md` 逐项检查。

## 核心规格速查

| 项目 | 数值 |
|---|---|
| 画幅 | 1920×1080，30 fps，横屏 |
| 时长 | 11–12 分钟（674 s / 700 s） |
| 语速 | 5.9 字/秒，约 350 字/分钟 |
| 平均镜头长 | 3.1 s（节奏快的期）~ 5.1 s（节奏慢的期） |
| 镜头长中位数 | 1.7 s ~ 3.6 s |
| 最快段落 | 43 刀/分钟（列举 + 数据段） |
| 最慢段落 | 2 刀/分钟（主持人 + 叠加图形持续说明） |
| 主持人回到画面 | 每 30–60 秒一次，作为"锚点" |
| 强调色 | 薄荷荧光绿 `#00EC8E`（实测取样） |
| 警示色 | 正红 `#E5262B`，只用于"拒绝/危险/亏损" |
| 字幕 | 白字无底框、细阴影，底部居中，单行 ≤16 字，不加标点 |
| 角标 | 右上角常驻"差评君 + bilibili"小白字 |
| 响度 | -15 LUFS 积分响度（B站标准），LRA ≈ 5 LU |
| 音乐床 | 全程铺底，比人声低 ~20–22 dB，几乎没有静音 |

## 不可省略的风格签名

- 冷开场是一个**直接问观众的问题**，接 3–5 句生活化的排比（"陌生号码不接、座机不接、外地号码不接"），在 20–25 秒内抛出标题问题。
- 标题卡：**超大号粗体汉字铺满画面 + 一个实物主体压在字上**（红色电话压在"失去信任"上）。
- 片头 sting：暗场 → 蓝色光线划过 → CRT 显示器亮起（频道标识），口播同时说"大家好，我是差评君，今天我们就来聊聊……"。
- 所有外部素材都放进**素材窗**（圆角内框 + 左上"来源：xxx"+ 左侧刻度 + 底部播放点），从不满屏裸放。
- 文件/新闻截图一定是**透视倾斜 + 缓推 + 绿色荧光笔扫过关键句**，左上角有圆形主持人头像。
- 数据图白底、宋体标题、**绿柱从 0 长出来**，数值逐个出现。
- 结尾固定：落点金句后接"好了，这里是差评君，这就是我们今天的内容……一键三连……拜托拜托关注一下我们……我们下次再见"，画面依次是创作清单（资料来源）→ CRT + 霓虹三连图标 → 白色大"差评"字标。

## 换成你自己的品牌

差评君的频道名、字标、主持人形象和演播间属于原作者。做自己的视频时只保留**结构、节奏、动效语法和配色逻辑**，把下列内容换成自己的：
频道名和自我介绍句、右上角角标、片头 CRT 里的标识、结尾字标、演播间布景、主持人。强调色可以保留绿色，也可以换成自己的品牌色，但全片只用一个强调色。
