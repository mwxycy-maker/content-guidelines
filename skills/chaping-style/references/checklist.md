# 交付前检查清单

## 文案
- [ ] 0:25 之前抛出了核心问题，开头第一句是对观众的提问或一个新闻事件
- [ ] 自我介绍句 + "今天我们就来聊聊……" 落在片头 sting 上
- [ ] 每个数据都有机构名、年份、精确数字
- [ ] 至少一处"很多人以为……其实……"的反常识
- [ ] 至少一处"但另一方面"的转向
- [ ] 至少 2 个可画出来的具体比喻，每 30–60 秒一个轻松的梗
- [ ] 结尾回扣开头意象，金句收在一个短词上；固定结尾话术完整

## 画面
- [ ] 每句字幕都有对应的画面类型（H/W/D/C/G/I/M/X/T）
- [ ] 外部素材全部进素材窗，标了来源
- [ ] 文件截图有透视、缓推和绿色荧光笔
- [ ] 数据图白底宋体标题、绿条生长、数值与口播同步
- [ ] 全片只有一个强调色（绿），红色只用在负面信息上
- [ ] 主持人每 30–60 秒回到画面；金句用近景
- [ ] 右上角角标全程常驻（包装段除外）

## 节奏
- [ ] 平均镜头长 3–5 s，中位数 1.7–3.6 s
- [ ] 列举段每个词一刀
- [ ] 快慢交替周期 60–90 s，没有连续 2 分钟以上相同切速
- [ ] 句间气口剪干净，只在金句前留半拍

## 声音
- [ ] 音乐床从头到尾不断，按章节换曲
- [ ] 音乐比人声低约 20 dB，并对人声闪避
- [ ] 弹出动效配了低电平音效
- [ ] 成片 -15 LUFS，真峰值 ≤ -1 dBTP，LRA 4–6 LU

## 字幕
- [ ] 白字无底框，底部居中，单行 ≤16 字，无标点
- [ ] 字幕出现时间与画面切点对齐
