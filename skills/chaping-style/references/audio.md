# 音乐、音效与混音

## 实测（可复现的数值）

| 指标 | 电话期 | 盗版期 | 目标 |
|---|---|---|---|
| 积分响度 | -19.5 LUFS | -14.9 LUFS | **-15 LUFS**（B站推荐，-14 到 -16 都可） |
| 响度范围 LRA | 4.7 LU | 5.8 LU | 4–6 LU（重压缩，音量非常平） |
| 人声段 RMS 与句间底噪差 | 18–22 dB | 20–23 dB | 音乐床比人声低约 20 dB |
| 低于 -45 dBFS 的时间 | 2.7% | 0.8% | <3%，几乎没有真正的静音 |

每分钟的人声电平和底噪电平都非常稳定（±2 dB），说明音乐床全程不断，并且在人声下方持续闪避（ducking）。

## 音乐床

> 以下曲风是根据频道一贯做法和画面情绪给出的建议，不是从音频里测出来的；数值部分是实测。

- **全程铺底**，从第一帧到最后一帧。没有"无音乐的纯人声段"。
- 曲风：低存在感的电子/氛围/Lo-fi 器乐，中速（85–110 BPM），以 pad、钢琴、合成器琶音、轻鼓为主，**不要人声、不要抢耳的主旋律**。
- **按章节换曲**：每个大段（约 1.5–3 分钟）换一首，换在主持人回到画面的那句转折句上，用 1 s 交叉淡化或直接硬切在重拍上。
- 情绪对应：
  - 钩子：悬疑、稍紧张，带脉冲低音。
  - 历史/数据段：轻快、有节拍推进感。
  - 事件/诈骗/危险：暗色、低频 drone。
  - 抒情回忆：钢琴或温暖 pad。
  - 落点金句：音乐抬升（+3–4 dB）并在金句最后一个词后收住。
- 片头 sting 和片尾字标各有一个**独立的品牌音效**（合成器扫频 + 低频冲击），和音乐床分开。

## 混音参数

- 人声：高通 80 Hz → 去齿音 → 压缩（比率 3:1–4:1，增益衰减 4–6 dB）→ 限制器。人声 RMS 约 -18 dBFS（成片 -15 LUFS 时）。
- 音乐床：基础电平比人声低 20 dB；用侧链压缩或自动化在人声出现时再闪避 3–6 dB，attack 10 ms、release 250–400 ms。没有人声的包装段（sting、结尾）音乐回到人声电平附近。
- 整体总线：轻度压缩 + 真峰值限制 -1 dBTP，响度归一到 -15 LUFS。
- HyperFrames 里用 `hyperframes-audio` 做 ducking 和总线限制。

## 音效（SFX）

画面每次"弹出"都有一个短促的音效，但电平低（比人声低 10–15 dB），不抢戏：

| 画面动作 | 音效 |
|---|---|
| 图标/标签弹出（M4–M7） | 轻 pop / UI click |
| 荧光笔扫过（M8） | 短 swish 或马克笔划纸声 |
| 数据条生长（M9） | 上升短音或轻 tick 连击 |
| 素材窗入场（M10） | 极轻 whoosh |
| 号码瀑布 + 红条（M1） | 低频 hit + 电话忙音/来电铃声片段 |
| 标题卡（M3） | 重低音 boom + 混响尾 |
| 素材窗里的原声 | 保留 -25 dB 左右做环境，口播不停 |

素材原声偶尔会被放大 1–2 秒当作"证人发言"（新闻主播一句话），这时音乐和口播都让开。
