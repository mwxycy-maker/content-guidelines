# 剪辑节奏与切点

## 实测数据

场景切换检测（ffmpeg scene > 0.22）：

| | 电话期（674 s） | 盗版期（700 s） |
|---|---|---|
| 镜头数 | 216 | 137 |
| 平均镜头长 | 3.12 s | 5.11 s |
| 中位数 | 1.67 s | 3.60 s |
| P10 / P90 | 0.20 s / 7.07 s | 0.90 s / 9.80 s |
| 最长镜头 | 43 s（主持人 + 叠加图形） | 36 s |

每分钟切点数：

- 电话期：`15, 25, 43, 11, 2, 14, 26, 27, 15, 12, 22, 5`
- 盗版期：`14, 7, 6, 6, 6, 13, 9, 10, 16, 22, 14, 13`

注：叠加图形在主持人镜头上弹出时，检测器不算切点，所以"感知上的画面变化"比上表更密，大约每 2–3 秒一次。

## 节奏曲线

把全片看成一条"快—慢—快—慢—收"的曲线：

1. **钩子段（0:00–0:25）**：15–25 刀/分钟，每一句字幕一个新画面。
2. **片头（0:25–0:31）**：一个连续的 sting，不切。
3. **主持人进入（0:31–1:00）**：主持人中景，切近景 2–3 次，第一组数据图插进来。
4. **历史/事件段**：最快，25–43 刀/分钟。**列举的每个词一个镜头**，0.5–1 s 一刀（"房地产/保险/装修/教培/贷款"五个镜头三秒内切完）。
5. **机制说明段**：最慢，2–10 刀/分钟。主持人长镜头上不断弹出图形，或者一份文件拆成多个缓推镜头。
6. **另一面/代价段**：回到 12–25 刀/分钟。
7. **抒情与落点**：放慢，主持人近景长镜头，配隐喻大场面 4–6 s/镜。
8. **结尾**：包装动画，不切。

快慢交替的周期约 60–90 秒。连续 2 分钟以上同一种切速就要调整。

## 切点规则

- **切在句首，不切在句中**。新字幕出现的那一帧 = 新画面出现的那一帧（或提前 2–4 帧，让画面先到）。
- 说到具体名词（机构名、产品名、年份）时，画面必须就是这个东西。说"工信部"就出工信部大楼素材，说"2013 年"就出巨大的 2013。
- 主持人每 30–60 秒回到画面一次，作为观众的锚点。回到主持人时通常是一个**观点句或转折句**（"但……""放到今天……"）。
- 同一机位的主持人镜头之间用跳切（中景 ↔ 近景），不用转场。
- 数据图之间用**原地变化**而不是切：同一张图里柱子长出来、数值更新、下一根柱子出现。
- 一份文件拆镜：全景 → 推到第一段高亮 → 推到第二段高亮，每个 2–3 秒。

## 转场

- 95% 是**硬切**。
- 章节转换偶尔用：白闪 2 帧、快速推镜（push）、或直接从素材窗切回主持人。
- 片头 sting 前一个镜头用标题卡压暗收住；片尾用推远进 CRT 的连续镜头。
- 不用交叉溶解、不用花哨转场插件。

## 句间停顿

- 口播的气口全部剪掉，句与句之间间隔 0–4 帧。实测全片低于 -45 dBFS 的 100 ms 窗口只占 0.8%–2.7%。
- 唯一保留的停顿是**金句前的半拍**（约 0.3–0.5 s），让音乐抬一下再说出最后一个词（"……社会信任"）。
