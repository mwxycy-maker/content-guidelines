# 画面语言：九种镜头类型

分镜时给每句字幕标一个类型代号。两期样片里各类型的大致占比如下（按抽帧统计，±5%）：

| 代号 | 类型 | 电话期 | 盗版期 |
|---|---|---|---|
| H | 主持人 A-roll（含叠加图形） | 35% | 35% |
| W | 素材窗（外部视频） | 25% | 20% |
| D | 文件/新闻/网页截图 | 12% | 12% |
| C | 数据图 / UI 卡片 | 8% | 5% |
| G | 极简图形解释（浅灰底） | 3% | 12% |
| I | 漫画风插画 | 7% | 2% |
| M | 3D 白模/产品渲染 | 7% | 3% |
| X | 隐喻大场面（AI 生成，电影感） | 0% | 6% |
| T | 片头片尾包装 | 3% | 3% |

## H 主持人 A-roll

- 中景，人物居中偏下，头顶留 1/6 画面，桌上有吊杆麦克风。
- 布景二选一：
  - **暗调演播间**：黑色吸音墙、左侧红色"ON AIR"灯箱、红色台灯、右后方一台显示频谱的小屏。整体低照度，人脸是唯一亮点。
  - **亮调工作室**：浅灰柜子、暖色层板灯、背景里虚化的海报。
- 自己的布景可以不同，但要有**一个红色暖光点 + 一个冷色屏幕光点**做景深层次。
- 同一机位做两种景别：中景（100%）和近景（约 115–125% 推近）。**强调句、金句、情绪句切近景**，其余回中景。最后一句金句是近景。
- 主持人镜头上经常叠图形（见 motion.md 的 M4–M7），叠图形时主持人镜头可持续 10–40 秒不切。

## W 素材窗

外部视频（新闻、广告、电影片段、他人视频）**一律不满屏**：

- 背景：深灰到黑的径向渐变（中心 `#3a3a3a` → 边缘 `#111`），或者浅灰版 `#d9d9d9 → #bdbdbd`。
- 画面：约 82% 宽，圆角 12px，1px 半透明白描边，轻微内暗角。
- 左上角小标签："▌来源：《节目名》2016xxxx"，绿色竖条 + 9pt 灰白字，带半透明黑底。
- 左边缘一列细刻度线，底部中间一排 5 个小点（像取景器/播放器 UI）。
- 素材窗内部可以做缓推（1.00 → 1.06，持续整个镜头）。
- 老素材、电影片段保留原有颗粒和偏色，不要修。人脸需要时打码（高斯模糊）。

## D 文件/新闻截图

- 白底文档截图做 **3D 透视倾斜**（rotateX 8–15°、rotateY -10–-20°），从右下向左上缓慢平移推近。
- 关键句被**绿色荧光笔从左到右扫亮**（背景色 `#00EC8E` 约 60% 不透明），可同时出现两三处。
- 关键数字单独用黑底白字或绿底黑字小框标出。
- 左上角圆形主持人头像（直径约 180px，绿色 3px 描边），表示"我在读这份文件"。
- 一份文档通常拆成 3–5 个镜头，每个镜头推到不同段落，配合口播逐句读。

## C 数据图 / UI 卡片

- 白底或极浅灰底，标题用**宋体粗体**（思源宋体 Heavy），黑色，居中顶部。
- 横向条形图：条为 `#00EC8E`，从 0 长到目标值（0.6 s, ease-out），数值标签跟随末端，保留两位小数。
- 坐标轴、刻度为浅灰细线；左下角极小字注明数据来源。
- 第二种形式是**伪 App 界面卡片**："欢迎回来，XXX"的仪表盘 UI，左侧图标栏，卡片里放报告标题和折线、关键数字（如 `2,300,000+` 绿底高亮）。镜头在卡片上推近到关键数字。

## G 极简图形解释（技术原理）

用于讲原理（编译、加壳、逆向）：

- 背景 `#e6e6e6` 纯色，画面中央一个元素，背景铺**巨大的半透明关键词汉字**（如"编译""乱码""脱壳"，字高约 60% 画面，颜色比背景深 6–8%）。
- 元素是黑色圆角 App 图标块、浅色代码窗口卡片（带三个圆点的标题栏）、绿色标签胶囊（"差评君.exe"）。
- 小字气泡（名字/逻辑/注释）从图标后方飞出又被吸回，表示"信息丢失"。
- 一个概念一个画面，镜头 2–4 秒。

## I 漫画风插画

- 用于还原新闻事件和人物情境（无法拍到的过程）。
- 风格：美式漫画/半调网点、粗墨线，青绿 + 暗红 + 米黄的限定色板；或者黑白报纸半调。
- 每张图 Ken Burns 推近 3–4 秒，同一场景可做 2–3 张表情变化帧（接电话的人逐渐紧张）。

## M 3D 白模与产品渲染

- 冷开场常用：手机 3D 渲染（来电界面、通知胶囊）、桌面俯拍复古物件（红色拨盘电话、诺基亚、胶卷、TIME 杂志）。
- 白色/灰色石膏质感人形白模 + 巨大宋体年份数字（"2013"）+ 白色卡片物件（SIM 卡、身份证），用于讲制度和身份。
- 3D 场景的运动：慢速环绕或推拉，景深浅。

## X 隐喻大场面

- 讲到核心隐喻时，用 AI 生成电影感画面让比喻具象化：莎士比亚站在一群猩猩中间、手持蜡烛、背后光圈。
- 只在论证高潮和结尾出现 3–6 个镜头，节奏放慢（4–6 秒/镜），配音乐抬升。

## T 片头/片尾包装

- **标题卡**：巨大粗体汉字（主题四字词，如"失去信任"），一个实物主体压在字中间（前景遮挡部分笔画），背景是上一镜的桌面场景做暗化。持续约 2.5 秒。
- **频道 sting**：全黑 → 一道蓝色光线自下而上划过 → 多道光线扫开 → 暗场中 CRT 显示器亮起频道标识，地面有蓝色反光，约 5 秒，正好覆盖"大家好我是XX，今天我们就来聊聊……"。
- **结尾**：浅青色背景"创作清单"卡片（资料来源列表，叠三层卡片）→ 推远进 CRT 屏幕 → 周围浮起点赞/投币/收藏霓虹图标 → 白色巨型频道字标填满画面，CRT 在字标前，"我们下次再见"。

## 常驻元素

- 右上角角标：频道名 + 平台 logo，白色 60% 不透明，高约 22px，距边 24px。片头 sting 和结尾字标时隐藏。
- 字幕：思源黑体 Medium，36px（1080p），白色，2px 黑色 40% 投影，底部安全区上方 40px，居中，单行，无标点。人名、术语加中文引号保留"柠檬化"。
