# 动效库（10 个标志性模板）

通用缓动：入场 `power3.out`（或 cubic-bezier(.2,.8,.2,1)），出场 `power2.in`。时长单位为秒（30 fps）。
所有动效都"快进慢停"：0.25–0.45 s 到位，然后保持静止或极慢漂移。不用弹跳（back/elastic）或者夸张旋转。

HyperFrames 实现见 `assets/chaping-motion.js`，函数名与下表编号对应。

---

### M1 号码瀑布（kinetic number list）
- 场景：钩子段，表达"大量陌生号码"。
- 黑底，多行灰白号码（"150 XXXX XXXX"，等宽或衬线数字，字号 64–96px）在 3D 透视中斜向排列，整体缓慢上移 + 轻微运动模糊。
- 0.5 s 后其中一行被**红色横条**（`#E5262B`，80% 不透明）从左扫亮，上方弹出小红标签"不接"。
- 接一个切：单个号码居中放大"浙江 杭州 / 137 XXXX XXXX"。

### M2 手机来电胶囊堆叠
- 3D 渲染手机斜放，界面上通知胶囊（"陌生号码 / 座机号码 / 外地号码"）每 0.6 s 从上滑入一个，配红色挂断按钮。
- 下一句时胶囊全部翻转成黑色"骚扰电话"标签（逐个 0.1 s 错开）。

### M3 标题卡：大字 + 遮挡主体
- 上一镜桌面场景压暗到 40% 并转灰。
- 四个巨型粗体白字（字高约 75% 画面，可略带粗糙质感）0.3 s 内从 110% 缩到 100% 并淡入。
- 实物主体（抠像 PNG）放在字的前景层，压住中间笔画。整体持续 2.5 s，镜头极慢推近 3%。

### M4 主持人周围的纸片图标 + 绿色连线
- 主持人中景上，白色纸片（拼图块形状，带细黑描边和投影）围绕人物逐个弹出：每个 0.25 s scale 0.6→1 + 淡入，错开 0.4 s，跟着口播的每个名词出现（"注册网站→地球图标，网购→购物车，快递→箱子，银行卡→卡片，买房→房子"）。
- 每个图标与人物中心之间画一条**绿色虚线**，虚线中段一个绿底黑字小标签（"手机号"）。虚线用 stroke-dashoffset 从图标端画向中心，0.4 s。
- 收尾：所有拼图块飞到人物前方拼合成一张**黑白线描肖像**，外框绿色细线。

### M5 信息标签 + 弧形箭头
- 在主持人身边出现黑底白字/白描边的小卡片："姓名：XXX""电话：123-XXXX-456""地址：XX区XX号"，带细绿色弧形箭头指向人物。
- 逐个出现，每个 0.3 s，间隔跟口播。

### M6 竖向绿色标签链
- 画面左侧一条从顶部垂下的**绿色竖虚线**，标签胶囊（绿描边、深色底、绿字，如"内鬼""收集倒卖""房产中介"）沿着线逐个出现，每次新标签出现时线往下延长。
- 用来展示产业链、流程、层级。

### M7 左上角号码/条目列表
- 左上角绿底黑字小块逐行出现（"95XXXX / 96XXXX / 400XXX"），每行 0.2 s，行距紧。
- 也可以单个标签出现在人物旁边（"呼叫中心公司"），绿色手写感斜体。

### M8 文件透视推进 + 荧光笔
- 文档截图放在 3D 平面上：rotateX 10°、rotateY -15°、轻微 rotateZ -3°，带柔和投影。
- 整个镜头内从 scale 1.0 → 1.08、x 向左平移 40px，linear。
- 第 0.4 s 起，荧光笔条（`#00EC8E` 60%）从左到右 0.5 s 扫过关键句；多处高亮依次 0.3 s 错开。
- 左上角圆形头像以 scale 0.8→1 弹入。

### M9 数据条生长
- 白底，宋体标题先出（0.3 s 淡入 + 上移 10px）。
- 每根条从左向右长出 0.6 s，`power3.out`，数值标签从 0 数到目标值（保留两位小数），条与条错开 0.25 s。
- 口播说到哪个数，哪根条才长出来；已经出现的条保持。
- 卡片式 UI 版本：卡片整体从右侧 3D 斜着滑入，然后镜头推近到 `2,300,000+` 绿底高亮数字。

### M10 素材窗入场
- 窗口本身从 scale 0.96 + 不透明度 0 → 1，0.3 s。
- 来源标签在 0.15 s 后从左滑入。
- 窗口内视频缓推 1.00→1.06（全镜头时长，linear）。
- 连续多个素材窗之间硬切，只换窗内内容，窗框保持不动（观众感觉在同一个"播放器"里翻看证据）。

## 片头 sting 时间线（约 5 s）
| t | 事件 |
|---|---|
| 0.0 | 全黑，一道细蓝光（`#2F8BFF` 发光）从画面下中部斜向上划过 |
| 0.6 | 一束竖直蓝光从底部升起 |
| 1.2 | 6–8 道蓝光扇形扫开，地面出现反光 |
| 2.0 | 光线收拢变为地面上的蓝色光斑，镜头推近一台复古 CRT 显示器 |
| 2.6 | CRT 屏幕亮起频道标识（青色屏幕底），机身两侧绿色小指示灯 |
| 5.0 | 硬切到主持人 |

## 结尾时间线（约 12 s）
| t | 事件 |
|---|---|
| 0.0 | 浅青底"创作清单"卡片（三层叠卡，标题左侧绿色竖条），列出资料来源，缓推 |
| 3.0 | 卡片缩进 CRT 屏幕，镜头拉远到暗场桌面 |
| 5.0 | 点赞（粉）、投币（黄）、收藏（蓝）霓虹图标从 CRT 两侧浮起 |
| 7.5 | 白色巨型频道字标从中心爆开铺满画面（0.2 s 白闪），CRT 在字标前方 |
| 12.0 | 结束 |
