# 口播稿结构与语言

## 量

- 全片 3900–4150 字（两期实测 3923 / 4137），语速 5.9 字/秒。
- 写稿时按 **350 字 ≈ 1 分钟** 估时长。
- 字幕切成 ≤16 字一句，平均一句约 2.2 秒。剪辑的切点也跟着这个句子节奏走。

## 段落骨架（以 11:15 为例的时间占比）

| 段落 | 时间 | 占比 | 做什么 |
|---|---|---|---|
| ① 钩子 | 0:00–0:25 | 4% | 问观众一个问题 → 3–5 句生活化排比 → 抛出核心问题"究竟是怎么一步步……的呢？" |
| ② 片头 | 0:25–0:31 | 1% | "大家好，我是XX，今天我们就来聊聊 + 一句话选题" |
| ③ 现状量化 | 0:31–1:00 | 4% | 一个反差数据（"接过的≥5，打过的≈0"）+ 一个权威调查的具体百分比 |
| ④ 历史与因果 | 1:00–6:00 | 45% | 按年份推进，每一段一个"转折点"：政策、事件、技术。每个论断都配**机构名 + 年份 + 精确数字** |
| ⑤ 反常识 | 6:00–7:30 | 13% | "很多人以为……放到今天，这个解释其实已经很难成立了"，用数据推翻 |
| ⑥ 另一面 / 代价 | 7:30–9:30 | 18% | "但……另一方面……"，把视角转到普通人、小开发者或系统本身付出的代价 |
| ⑦ 情绪与个人 | 9:30–10:20 | 8% | 主持人第一人称回忆（"小时候的我……"），一段抒情 |
| ⑧ 理论升维 + 金句 | 10:20–11:00 | 6% | 引一个经济学/数学/文学概念（柠檬市场、无限猴子定理、莎士比亚），收在一个短名词或名句上 |
| ⑨ 固定结尾 | 11:00–11:15 | 2% | 见下文 |

第二期的钩子换成了"新闻事件开场"（上个月某开发者用 AI 复刻了使命召唤 → 被下架 → 留下的问题），结构不变。

## 固定句式（可直接套用）

**钩子**
- "你最近一次 + 动作 + 是什么时候？"
- "不知道从什么时候开始，X 居然变成了 Y。"
- "如果说上个版本……比的还是……，那么当下最火热的版本答案，已经是……"
- "一个曾经…的X，究竟是怎么一步步……的呢？"

**推进**
- "这件事发展得有多早呢？" → 给出年份和数字 → "那是 2013 年，很多人那时候的手机连 4G 都还没用上。"（用同时代的生活细节给数字定位）
- "与此同时，另一群人开始……"
- "而要解释这种……，有一个时间点绕不过去：2013 年。"
- "这在当年还是个大新闻。可到今天，几十万条这个量级已经不够看了。"

**反常识**
- "一个很容易产生的误解是……放到今天，这个解释其实已经很难成立了。"
- "也就是说，它并没有……，只不过……"

**另一面**
- "故事讲到这里，似乎是一个……的爽文故事。但……"
- "一方面……另一方面……"
- "这并不是一种假设。"

**落点**
- "所以X这些年失去的，可能远不止……它还失去了一样曾经非常廉价，以至于我们几乎意识不到它存在的东西：社会信任。"
- 首尾呼应：开头提到的意象（莎士比亚、电话铃声）在最后一句再出现一次。

**固定结尾（逐字）**
> 好了，这里是XX，这就是我们今天的内容。如果你觉得好的话，欢迎你一键三连。如果你还有什么想说的，欢迎在评论区和弹幕里和我们互动。最后，拜托拜托关注一下我们，也可以关注一下我们的公众号XX。我们下次再见。

## 语言质感

- **严肃题材 + 网络口语调味**：每 30–60 秒放一个轻松的梗，比如"骚扰电话已经开始稳定地陪中国人上下班了""燃烧 CPU 做出快速回复""直接当老板，而且是逻辑最简单的那类土老板""恨不得让开发者把游戏卡带吃下去"。
- **比喻要具体、可画出来**：小鸡变回鸡蛋、猫鼠游戏、割了一茬又长一茬的野草、给陌生号码设计一套统一的制服、交到更多人手里的宝剑。写比喻时就要想好对应画面（见 visual-language.md 的"隐喻插画"）。
- **数据必带出处**："艾媒咨询在 2024 年做过一次全国随机抽样调查""360 发布的《2013 年中国手机安全状况报告》""工信部在《2014 年通信业统计公报》里直接提到"。精确到小数点（43.01%）。
- **短句为主**，一句话一个信息点，方便切字幕和切画面。列举时一个词一句："房地产、保险、装修、教培、贷款"。
- **观点克制，结论开放**：不站队到底，最后给出两难（"开发新功能和搬走别人成果的边界应该在哪"），落在"唯一能做的可能也只有……"。
- 称呼观众偶尔用自造的粉丝名（"差友们"），换成自己频道的。
