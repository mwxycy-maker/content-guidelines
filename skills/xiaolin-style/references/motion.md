# 动效模板

缓动：入场 `power3.out` 0.3–0.5 s；印章、外号用 `back.out(2)` 0.25 s 砸下；画中画常驻不动。整体比差评、影视飓风更"花"，元素多、发光多，但始终在深色底上保持层次。

### L1 金色标题卡
- 背景：深色纹理视频（数据流/城市俯拍），亮度压到 30%。
- 中文金色衬线字（思源宋体 Heavy，金色渐变 `#f3dca0→#b8893a`），字距 0.6em，0.8 s 从模糊 + 字距更大收拢到位；英文小字宽字距 0.4 s 后淡入。
- 整体 3 秒内缓推 1.00→1.05。

### L2 画中画
- 圆形：左下，150–170px，金色 2px 边 + 外发光；进入时 scale 0.8→1，0.25 s。
- 竖卡：右侧，260×340px，金色细边；随信息图布局一同滑入。
- 整段常驻，切素材时不跟着闪。

### L3 公司气泡
- 半透明玻璃圆（背景模糊 + 1px 白描边 + 内高光），直径 180–260px，logo + 中文名 + 下方市值胶囊。
- 依次从中心向外弹出，错开 0.15 s；整体缓慢漂浮（确定性 sin，振幅 6px，周期 4 s）。
- 被否定的气泡：灰度化 + 红色印章砸下（scale 1.6→1，旋转 -8°，0.25 s）。

### L4 饼图拆解
- 大饼图 0.8 s 顺时针画出；关键扇区高亮并略外移 20px，标签卡从扇区引出细线后弹出。
- 人物头像落在扇区尖端，配外号。

### L5 斜放走势图
- 白纸卡片 rotateY -18°、rotateX 8°，从右侧滑入。
- 折线从左到右 1.2 s 画出；转折点出现时巨大红色百分比数字（"-70%"）以 scale 1.4→1 砸到图上。

### L6 合同卡片填空
- 米色纸张，标题宋体；字段占位为灰色，口播说到时该字段底色从左到右刷成彩色（蓝/黄/红/绿），0.3 s。

### L7 多空对阵卡
- 右侧上下两张竖卡，分别写"多头""空头"；盈亏数字在卡下方用绿/红胶囊弹出，随走势图同步更新。

### L8 毛笔大字章节卡
- 人物照片做背景（压暗 50%，可加紫色调）；两到四个书法大字逐字砸入（每字 0.12 s，带轻微抖动和墨迹散开）。

### L9 小测验
- 渐变面板（青绿→紫，圆角 20px）从下方升起；问题先出，四个选项按钮依次弹出（错开 0.12 s）；揭晓时正确项放大 1.05 并发光，其余降到 40% 透明度。

### L10 文件翻译叠字
- 英文文件截图全屏，关键句加粗；中文红色粗体标题从左侧滑入叠在该句上方。
