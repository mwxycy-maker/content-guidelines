# 交付前检查

- [ ] 开场"嗨！朋友们，我们今天来说说……"，40 秒内抛出最大数字和看点
- [ ] "废话少说"接金色标题卡
- [ ] 主要人物都有外号和至少一句"台词"
- [ ] 每个专业词都配了生活类比
- [ ] 非主持人画面都带画中画（圆形左下或竖卡右侧）
- [ ] 信息图统一深色底 + 金色点缀，元素逐句出现
- [ ] 有至少一个红色印章/大红数字的"砸"的瞬间
- [ ] 章节转折用毛笔大字卡
- [ ] 结尾回到人性/永恒主题
- [ ] 平均镜头长 2.5–3 s，中位数约 1.6 s，开头一分钟 40+ 刀
- [ ] 音乐全程铺底，比人声低 17–20 dB；成片 -14 LUFS
- [ ] 字幕白色粗体略斜带阴影；右上角常驻角标
