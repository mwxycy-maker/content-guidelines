# 口播稿

## 量
- 约 6.1 字/秒，按 **365 字 ≈ 1 分钟** 估时长。14 分钟约 5000 字，26 分钟约 9000 字。
- 短句多，一口气一句，大量语气词（"啊""吧""呢""你看"）。

## 结构

| 段落 | 占比 | 做什么 |
|---|---|---|
| ① 招呼 + 炸点 | 前 40 秒 | "嗨！朋友们，我们今天来说说 + 选题"。马上用观众熟悉的事物做参照放大数字（"你还记得前两年的两大收购案吗？微软收购动视暴雪、马斯克收购推特，这一笔是那两个的总和：1109 亿美元"），再抛一个反常识的看点（"一个超级富二代居然能接连吞下两大好莱坞巨头"） |
| ② 进标题 | 1 句 | "废话少说，我们赶紧来看看……" → 标题卡 |
| ③ 概念入门（概念类选题） | 10–20% | 用最小例子讲清概念：主持人自己当"甲方"，"老王"当"乙方"，约定价格，涨跌各亏多少，配合同卡片和走势图 |
| ④ 人物登场（事件类选题） | 10% | "今天咱们故事的主角叫……"，交代身世、性格、动机，带一句类比（"有点美国版……的意思"） |
| ⑤ 情节推进 | 50–60% | 按时间线讲"第一招、第二招"，每一步都有对手、有障碍、有破局；遇到专业概念就停下来用一个生活类比解释 |
| ⑥ 小测验（可选） | 1 处 | "考考大家：面值成交量最大的期货产品是什么？"，给 4 个选项，停 2–3 秒再揭晓 |
| ⑦ 拆解底层逻辑 | 10–15% | "所以你看，明面上是……实际上……"，把整件事归纳成一个形象的比喻（蛇吞象） |
| ⑧ 收尾 | 最后 20 秒 | 两种收法：A. 回扣开头的金句或人性主题（"说到底，他凭借的是……的钱和……的权，你看到没有，大道至简，我们又回到了那个人类永恒不变的主题"）；B. 系列连载式，先总结本期三个要点（"高杠杆、容易做空、还非常隐蔽"），再预告下期更劲爆的内容（"我是想接着往下聊的，但好像这个进度条不太允许了，那我们就下期继续"） |

概念类选题的开头是另一种写法："嗨，朋友们，今天我们来聊一聊期货"→ 一句话说它有多大（"总成交量甚至超过了庞大的外汇市场，堪称金融产品之王"）→ 列出本期要回答的问题（"它表面上是什么，本质上又是什么，有什么特点"）。

**拿自己举例**：讲概念时让主持人自己当例子里的角色（"就比方说我小Lin，在 3000 美元的位置做多了……"），甚至虚构一个和频道相关的产品（"Lin 指数期货 = 本账号全网月播放量 ÷ 100 万"），观众更容易代入。

## 语言质感
- **给人物配台词**：用第一人称演出人物心理（"不行，我不能再小打小闹了""我也出钱，算我一个"），每个主要人物至少一句。
- **起外号、拟人化**：老爹、大卫、姐姐；公司是"蛇"，被收购方是"大象"。
- **生活类比解释专业词**：期货 = 提前约定价格的买卖；做空 = 先卖后买；对冲 = 农民提前锁定麦价。
- **数字放到可感知的参照里**："全球前十的富豪，资产两千亿美元""是那两个收购案的总和"。
- **口头禅式衔接**："你看""咱说白了点""这就有意思了""我跟你说""关键是什么？"
- **轻度调侃**，但不阴阳怪气：对人物有点戏谑，对事实严谨。
- 每 1–2 分钟一个小高潮（反转、意外数字、台词）。
