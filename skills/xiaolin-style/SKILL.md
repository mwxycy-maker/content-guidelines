# 小Lin说风格 Skill

> 制作视频时，先遵守 [通用剪辑规则](https://github.com/mwxycy-maker/content-guidelines/blob/main/skills/content-video-editing/SKILL.md)。本 Skill 的样片数值、画面、口播、字幕、气口、配乐和交付做法只供参考；有差异时以通用剪辑规则为准。当期用户明确要求优先。

从两期样片提炼：《什么是金融赌场，它背后有什么秘密？》《史上最大现金收购案 富二代如何正确拼爹》。数值是实测。

一句话概括：**一个亲切的女主持人用聊天的口气把复杂的金融事件讲成一个有人物、有台词的故事，全程有她的画中画陪着，画面在主持人、深色金色调的信息图和新闻素材之间快速切换**。

## 样片风格特征（可选参考）

- **样片开场**："嗨！朋友们，我们今天来说说……"，配主持人挥手；然后 30–40 秒抛出最炸的事实和数字，再"废话少说，我们赶紧来看看……"进标题卡。
- **标题卡**：深色电影感背景（数据流纹理或城市俯拍）上，金色衬线中文大字宽字距排开（"期 货""金融产品之王"），下面一行英文小字宽字距（"Futures Contract"）。
- **主持人画中画永远在**：画面换成素材或信息图时，主持人以**圆形头像（左下，金边）**或**竖长方形卡片（右侧）**继续出现、继续说话和做表情。观众始终"看着她讲"。
- **信息图是深炭黑/深海军蓝底 + 金色和品牌色点缀**：玻璃质感的公司气泡（logo + 市值标签）、红色印章（"买不动"）、饼图拆股权、白纸斜放的股价走势图（红色大字"-70%"）、合同卡片（米色纸，关键字段彩色高亮）。
- **人物卡和外号**：把真实人物做成圆形头像牌，配夸张的中文外号（"老爹""姐姐"），关系用箭头连起来。
- **毛笔大字章节卡**：人物照片上压巨大的书法/毛笔字（"文娱帝国""破局"），用于章节转折。
- **互动小测验**："小测验 Lin Test"卡片，渐变色面板 + A/B/C/D 四个选项，揭晓时正确项高亮。
- **结尾**：事件类回到"人性/永恒主题"的一句感慨；概念类用"进度条不太允许了，我们下期继续"做连载预告。

## 换成你自己的品牌

保留叙事方式、画中画陪伴、信息图语法和节奏。频道名、主持人、霓虹灯签名招牌、"Lin Test"字样、角标换成你自己的。
