# 口播稿

## 量
- 教程期 5.3 字/秒，横评期 5.7 字/秒。按 **330 字 ≈ 1 分钟** 估时长。
- 短句，一句一个动作或一个结论，字幕切成 6–14 字一行。
- 说人话：专业词出现时马上用一句话翻译（"ComfyUI 是免费开源的 AI 绘画和 AI 视频生成工具""模型文件是真正负责生成视频的东西"）。

## 固定句式
- 开场："这应该是你目前能刷到的最……的……""为了搞清……到底是不是真的能打，我……"
- 转场设问："那如果……是不是就不能……了？哎，有办法。""有些小伙伴可能会问……"
- 解释缩写：拆字母逐个讲（"F 是首帧，L 是尾帧，2 代表转换，V 是 video，A 是音频，连起来就是……"）。
- 点评："整体完成度非常高""没有短板""但问题也是最大的"。
- 价钱："如果按照 API 计费，X 要花 321 块，这 35 倍的差距……"

## 语言质感
- **第一人称亲测**："我这台电脑""我一般常用的是""我个人推荐"，可信度来自"我真的跑过"。
- **俏皮话放句尾**，每 40–60 秒一处：网络梗（量大管饱、PUA 老板、撞墙也该认了）、自嘲（我也躺倒在了椅子上）。
- **给结论不含糊**：每轮都排名，最后一句话定调；但对自家推荐的东西也说缺点（本地版画质不如在线版、左右键是反的）。
- **为观众兜底**：文档、懒人方案、没显卡方案，让每种人都有路走。
