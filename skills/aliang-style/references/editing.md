# 剪辑节奏

## 实测

场景切换检测（ffmpeg scene > 0.22）：

| | MiniMax H3 教程（557 s） | DeepSeek 横评（380 s） |
|---|---|---|
| 镜头数 | 115 | 35 |
| 镜头长中位数 | 1.87 s | 4.23 s |
| P90 | 11.8 s | 24.1 s |
| 最长镜头 | 52.5 s（录屏连续操作） | 120.7 s（对比卡片段） |
| 每分钟切点 | 46, 20, 13, 4, 4, 4, 7, 8, 5, 3 | 6, 5, 17, 3, 3, 0, 0 |

注：录屏滚动、对比卡片在原画面里出现/放大、花字叠加，检测器都不计为切点。感知上画面每 2–3 秒就有一次变化（新卡片、新高亮、新花字）。不要按上表的低切点数理解成"画面不动"。

## 规则
- **前 1 分钟最快**：开场口播 + 花字 → 效果蒙太奇每 1–2 秒一刀，切在音乐重拍上。
- **口播和画面交替**：全屏口播一般 3–10 秒就切走，讲到具体操作立刻切录屏，讲完结论再回到口播。
- **录屏按步骤剪**：每一步只留"点下去那一下"和结果，等待、加载、下载过程全部剪掉或加速；一个步骤 2–5 秒。
- **对比段用原地变化代替切镜**：同一个浅灰底画面里，卡片依次出现、放大当前项、弹价签，一段可以 20–60 秒不切。
- **竞猜要停顿**：三个结果并排播放 15–20 秒不说话，只有音乐，然后再揭晓。
- 句间气口剪干净；吐槽句后不留停顿，直接进下一句。
- 转场：硬切为主；章节卡用黑底网格硬切进，花字自己做入场动画。
