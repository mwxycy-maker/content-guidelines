# 画面与分镜

## 镜头类型与占比（按每 5 秒抽帧估算，±5%）

| 代号 | 类型 | 教程期 | 横评期 |
|---|---|---|---|
| H | 博主全屏口播 | 30% | 35% |
| S | 录屏（带圆形画中画） | 45% | 20% |
| C | 对比卡片 / 结果并排（带画中画） | 0% | 40% |
| E | 效果展示蒙太奇（满屏成片，无画中画或小画中画） | 10% | 0% |
| T | 黑底网格花字章节卡 / 配置表（带画中画） | 15% | 5% |

## H 博主口播
- 中景，人物居中，胸前别领夹麦，手势多（数手指、比"两个"、双手比划）。
- 布景：家里的房间，背景虚化。教程期是暖白客厅（窗帘、电视墙、左侧霓虹闪电和星星灯牌），横评期是暗调房间，左侧蓝色"AI 阿亮"霓虹字 + 紫色氛围灯。
- 服装：纯色 T 恤（黑或白），胸前小 logo。
- 讲到某个模型时，**模型 logo + 名字直接贴在博主身边**（白色圆形图标 + 白色粗体名字，右上方），切到 VS 时左右各一个。
- 关键词花字直接叠在口播画面空处（"生成次数受限 / 模型选择受限 / 参数控制难"三行紫粉渐变字，或"量大管饱"竖排）。

## 画中画（核心签名）
- 圆形，左下角，直径约画面高度的 15%（1080p 约 160px），距左 20px、距底 20px，无边框或细白边。
- 画中画里是同一条口播录制，在说话、做表情，不是静帧。
- 录屏、配置表、对比卡、截图上都带；只有效果展示蒙太奇和满屏花字（"就找不回来了~"）时去掉。
- 偶尔用左侧竖长方形小窗代替圆形（"可电脑本地部署"那一镜）。

## S 录屏
- 浏览器、文件夹、ComfyUI 节点图、命令行都直接录，保持真实 UI。
- **操作位置用橙色虚线框标出**（下载链接、文件名、选项），鼠标指针保留。
- 录屏画面常做成**圆角卡片 + 投影**浮在黑底或浅灰底上，而不是满屏裸放，可以略微倾斜做 3D 透视。
- 需要强调的步骤加一行编号花字压在录屏底部（"1. 检查显卡驱动是不是最新的""3. 更新后重启电脑"）。
- 用到的另一个 AI 工具（让 agent 帮你部署）也录下来，输入框里的提示词要看得清。

## C 对比卡片（横评期）
- 浅灰紫渐变底（约 `#e8e8f0`–`#f0f0f8`），结果做成圆角白边卡片 + 柔和投影，三张并排或上下三排。
- 每张卡左上角模型 logo + 名字；卡片底部一行小字"用时 · Token · 金额"（如"14:28 · 5M Token · ¥7.8"）。
- 当前在讲的那张放大、其余缩小变暗。
- 竞猜环节：左侧大号灰色序号 1 / 2 / 3，先不标名字，揭晓时右侧依次弹出 logo。
- 汇总表：三行结果缩略图 + 三列"用时 / Token / 金额"大号数字。
- 游戏类结果用深紫黑底，卡片斜放带透视。
- 引用官方说明时，文档截图斜放，关键句青色荧光笔高亮。

## E 效果展示蒙太奇
- 满屏放模型生成的最好成片，右上角小字"XX 生成"注明来源。
- 风格要多样（MV、二次元、机甲、电影片头），每段 1–3 秒。

## T 花字章节卡与配置表
- 黑底 + 深灰细网格线。
- 花字：粗黑斜体，紫→粉横向渐变（约 `#7a5cff → #ff4fa0`），带轻微发光；配产品 logo 方块（紫色圆角）。
- 配置表：深紫半透明表格，两列"项目 / 建议起步配置"，讲到哪一行哪一行描边高亮。

## 字幕与常驻元素
- 字幕：白色粗黑体，带深色描边和投影，底部居中，1080p 约 36–40px，无底框，无标点。
- 横评期字幕更粗更大，描边更重。
- 没有常驻角标。
