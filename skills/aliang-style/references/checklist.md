# 交付前检查

## 共同
- [ ] 前 5 秒一句话抛结论或噱头
- [ ] 非口播画面都带左下角圆形画中画（满屏蒙太奇除外）
- [ ] 讲到模型时，logo + 名字贴在博主身边
- [ ] 至少 3 处紫粉渐变斜体花字
- [ ] 每个专业词都有一句大白话翻译
- [ ] 句尾吐槽/网络梗 3 处以上，至少一处坦白自己踩的坑
- [ ] 结论落在"省钱 / 免费 / 性价比"，并说清楚缺点
- [ ] 字幕白色粗体带描边，无底框无标点
- [ ] 成片 -14 到 -15 LUFS，LRA 约 4 LU

## 模式 A（部署教程）
- [ ] 开头 15 秒内有收藏钩子和"资料都整理在文档里"
- [ ] 先放 20–30 秒效果蒙太奇，再讲方法
- [ ] 有配置门槛表，并展示自己的电脑配置
- [ ] 同时给懒人方案（agent 一句话部署）和手动方案
- [ ] 每个操作位置都有橙色虚线框，步骤有编号
- [ ] 有"没有显卡怎么办"的云端方案
- [ ] 结尾提教学文档 + 一句温情收尾

## 模式 B（模型横评）
- [ ] 开头交代赌注（花了多少 token/钱）和比拼项目
- [ ] 第一个场景做成竞猜，停 15–20 秒再揭晓
- [ ] 每个结果标"用时 · Token · 金额"，每轮给名次
- [ ] 有一次价签对撞（便宜方 ×N 倍 贵方）
- [ ] 一句态度鲜明的总结论
- [ ] "加餐"接入教程（官方工具 + API Key + 第三方工具）
- [ ] 结尾"你用上了吗？评论区聊一聊"
