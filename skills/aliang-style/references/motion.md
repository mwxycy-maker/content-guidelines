# 花字、卡片与包装动效

通用缓动：入场 `power3.out` 0.25–0.4 s；价签和"VS"用 `back.out(1.6)` 0.25 s 砸入；其他不用弹跳。颜色值是看画面估的，不是精确取样。

### A1 紫粉渐变花字
- 粗黑斜体（思源黑体 Heavy 加 10° 斜切），紫→粉横向渐变（约 `#7a5cff → #ff4fa0`），外发光 8–12px 同色 40%。
- 入场：从 8px 模糊 + 透明 + 向右 30px，0.3 s 到位；多行时逐行错开 0.15 s。
- 用途：章节卡（黑底网格上居中）、口播画面上的关键词（放在博主身边空处）、参数提示（"倍数默认32"）。
- 收藏钩子版本：满屏大字"就找不回来了~"，带波浪号。

### A2 圆形画中画
- 进场 scale 0.85→1 + 淡入，0.25 s；之后常驻不动，切录屏时不跟着闪。

### A3 模型 logo 贴身
- 白色圆形 logo（直径约 120px）+ 下方白色粗体名字，出现在博主右上空处，scale 0.6→1，0.2 s。
- 两个模型对比时左右各一个，错开 0.15 s。

### A4 VS 分屏
- 斜向闪电分割：左蓝右橙红，双方 logo + 名字，中间白色斜体大"VS"砸入。持续 1.5–2 s。

### A5 录屏卡片
- 录屏缩到 80–85% 做成圆角卡片（12px 圆角、柔和投影），从下方 20px 淡入，可加轻微 3D 倾斜（rotateY -8°）。
- 操作位置的橙色虚线框（`#ff9a3c`，2px，dasharray 6 4）在点击前 0.3 s 画出。

### A6 配置表逐行高亮
- 深紫半透明表格，讲到哪一行，那一行白色细描边 + 略放大 1.03，0.2 s。

### A7 对比卡片
- 三张卡依次从下方弹入，错开 0.12 s。讲到某张时：该卡 scale 1.15 并前置，其余 scale 0.9 + 透明度 50%，0.35 s `power2.inOut`。
- 竞猜揭晓：右侧 logo + 名字逐行弹出，错开 0.2 s。

### A8 价签对撞
- 绿色描边胶囊"¥9.2"（左）先砸入 → 中间黄色斜体"×35" → 红色描边胶囊"¥321"（右）砸入并轻微震动 2 帧。

### A9 汇总数据表
- 三列"用时 / Token / 金额"，数字从 0 滚到目标值 0.6 s；最便宜的那行最后用绿色高亮。

### A10 打码/模糊过场
- 揭晓前把整张表做 12px 高斯模糊 + 横向运动模糊，0.3 s 后清晰，制造"马上揭晓"的感觉。

### 片头片尾
- 无独立片头 sting，开场直接口播。
- 教程期结尾：滚动展示教学文档页面，字幕"跟着文档一步步操作"。
- 横评期结尾：口播"我是XX，我们下期再见"，博主身边弹出主角模型 logo，硬切黑场。
