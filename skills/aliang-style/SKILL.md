# 跟着阿亮学AI 风格 Skill

从两期样片提炼：《MiniMax H3 本地部署教程》（9:17）《DeepSeek V4.1 Flash 对比 GPT-6.1 Sol / Claude Opus 5.5》（6:20）。数值是实测，不是印象。

一句话概括：**一个穿 T 恤的博主在挂着"AI 阿亮"霓虹灯的房间里，用大白话把一个刚发布的 AI 工具讲成"你也能马上用上"的事；一离开口播，画面就是录屏或对比卡片，左下角他的圆形头像一直在陪着说话**。卖点永远落在"省钱 / 免费 / 性价比"上。

这个账号有两种模式，先选一种：

| 模式 | 样片 | 适合 | 节奏 |
|---|---|---|---|
| **A. 部署教程** | MiniMax H3 | 开源模型本地部署、工具安装、工作流上手 | 8–10 分钟。开头 1 分钟快剪（46 刀），之后录屏为主，每分钟 3–8 个硬切 |
| **B. 模型横评** | DeepSeek V4.1 Flash | 新模型发布后与顶级模型同题比拼 | 6–7 分钟。对比卡片在原画面里逐个出现，口播段配画中画，最后"加餐"接入教程 |

## 使用流程

1. 选模式，写口播稿 → `references/script.md`
2. 画面类型与分镜 → `references/visual.md`
3. 剪辑节奏 → `references/editing.md`
4. 花字、卡片与包装动效 → `references/motion.md`
5. 声音 → `references/audio.md`
6. 交付前对照 `references/checklist.md`

用 HyperFrames 做花字和对比卡片时，先读 `hyperframes` 和 `hyperframes-animation` skill。

## 核心规格速查

| 项目 | 实测/规格 |
|---|---|
| 画幅 | 16:9 横屏。教程期 2560×1440 30 fps，横评期 1920×1080 30 fps |
| 时长 | 6–10 分钟 |
| 口播字数 | 教程期约 3000 字，横评期约 2200 字 |
| 语速 | 5.3 字/秒（教程，录屏处留操作时间）/ 5.7 字/秒（横评） |
| 字幕句长 | 平均 1.9–2.6 秒一句，单行 6–14 字 |
| 镜头长中位数 | 1.9 s（教程）/ 4.2 s（横评）。录屏和对比卡片在原画面内变化，检测器不计，感知上每 2–3 秒画面就动一次 |
| 最快段落 | 教程期第 1 分钟 46 刀（效果展示蒙太奇） |
| 积分响度 | -15.5 / -14.1 LUFS，LRA 4.0 / 3.9 LU |
| 主持人出镜 | 全屏口播约 30–35%；其余时间左下角圆形画中画常驻 |
| 字幕 | 白色粗黑体 + 深色描边/投影，底部居中，无底框，无标点 |

## 不可省略的风格签名

- **前 5 秒一句话抛结论或噱头**："这应该是你目前能刷到的最完整、最简单的……教程""我猛灌 5 亿 token 让它和……同台竞技"。
- **收藏钩子**（教程期）："大家点好收藏，视频划走就找不回来了，因为我把部署资料全部整理到文档中了"。配满屏霓虹渐变大字"就找不回来了~"。
- **先看效果，再讲方法**："不废话，直接看效果展示"→ 20–30 秒纯音乐蒙太奇，展示模型最好的成片。
- **左下角圆形头像画中画**：录屏、对比卡、截图上始终有一个圆形的博主头像在说话，直径约画面高度的 15%。
- **黑底网格 + 紫粉渐变斜体大字**做章节卡和关键词花字（"有显卡如何部署""安装模型文件""倍数默认32"）。
- **数字都要比给你看**：配置表逐行高亮，横评期每个结果下标"用时 · Token · 金额"，最后用"¥9.2 ×35 ¥321"这种红绿价签对撞收束。
- **口语吐槽收尾**：句尾加一句俏皮话（"哎，不是广告啊""是不是像极了你那个贼会 PUA 的老板""这你受得了吗"），并且坦白自己踩过的坑（余额用尽还让 Codex 查为啥连不上网）。
- **固定结尾**：教程期给"详细教学文档"兜底 + 一句温情收尾（"愿你心中的画面，都能成为视频里的故事"）；横评期"你用上了吗？体验怎么样？咱们评论区聊一聊。我是阿亮，我们下期再见"。

## 换成你自己的品牌

"AI 阿亮"霓虹灯、频道名、博主形象和"我是阿亮"属于原作者。做自己的视频时只保留**结构、节奏、画中画语法、花字配色逻辑和对比卡片的版式**，把频道名、霓虹招牌、自我介绍句换成自己的。
