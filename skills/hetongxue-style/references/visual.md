# 画面、布景与拍摄

## 两种模式的画面构成（按抽帧估算，±5%）

| 类型 | 创意制作 | 体验长片 |
|---|---|---|
| 制作/使用过程实拍（手部、物件、同事） | 45% | 10% |
| 主持人出镜讲解 | 15% | 35%（多数在长镜头中走动） |
| 产品/成品展示（含三维标注） | 25% | 30% |
| CG 渲染与合成 UI | 10% | 20% |
| 霓虹演播间 / 片尾 | 5% | 5% |

## 主持人
- **创意模式**：主持人是"做东西的人"。广角近距离手持自拍式讲解（脸占画面 1/3，背景是作品），或者在工作台前动手；表情生动，会对着镜头做小动作（摸下巴思考）。
- **体验长片模式**：全身或中景站在实景布景里，边走边讲，镜头跟随移动；穿黑色 T 恤，手里拿着产品。
- **结尾演播间**：黑色背景，墙上发光的霓虹字母标志（蓝色竖线 + 红色横线组成的字母），左侧一盏暖色球形灯，后方架子上有小玩具和霓虹小图标。中景正面，柔光。

## 实景搭建（核心签名）
为讲清楚一个点专门搭场景，而不是放一张图：
- 讲光圈：一个暖色调房间，圣诞树 + 串灯 + 若干点光源，主持人在里面拍给你看星芒。
- 讲快门：墙上投一个圆形强聚光，主持人在光圈里抛球。
- 讲样张对比：在布景墙上挂两个真实的金色画框，画框里是 F4 和 F1.48 的照片，左下角写参数。
- 讲景深：白板上画示意图，后面真的站着一只羊驼。
- 讲测试：搭一个吧台/机器臂场景复现问题。

## 三维标注（核心签名）
- 文字像实物一样"贴"在物体旁边，跟随摄像机运动（需要做摄像机追踪）。
- 字体：粗黑体，大号主字 + 下面一行小字说明（"舵机 / 控制外侧柜门""半导体制冷片 / 柜体保温制冷"）。
- 质感：白字带彩色霓虹外发光，或者彩虹色散/RGB 分离效果；关键参数用大号斜体数字贴在地面或物体上（"35000Pa 吸力""最低 7.95cm"）。
- 偶尔在物体表面贴一段带 emoji 的吐槽字。

## CG 与合成 UI
- 产品渲染：干净的浅灰/白色无缝背景，柔和顶光，产品多角度旋转；或黑色背景配白色线框几何装饰。
- 手机 UI 放大成半透明圆角卡片浮在实景空间里（参数面板、相机控制面板），带轻微景深。
- 讲存储原理：深蓝网格背景上的半透明立方体（粉色/青色）+ 发光粒子；数据用胶囊框（"256GB""1TB"）。
- 续航对比：青色网格纸背景，两台手机俯拍并排，大号白色数字写时长和功率。
- 玻璃质感 3D 图标（对话气泡、相册图标）漂浮在洞洞板背景前。
- 倒计时：左上角圆形倒计时计数（"18s""16s"…），给一段演示加时间压力。

## 实拍质感
- 色彩明亮干净，饱和度适中，白平衡准；室内大量使用实用光源（串灯、霓虹）。
- 镜头运动流畅：稳定器跟随、滑轨推近、低机位贴地跟拍（扫地机器人视角）。
- 制作过程多用俯拍和手部特写，快速剪辑。

## 常驻元素
- 右上角："频道名 + bilibili"小白字，约 20px。
- 字幕：白色中等粗细，32–36px，底部居中，无底框，轻阴影。
- 片尾：黑底霓虹风"Credits:"和"BGM:"两栏，列出制作人员和曲目。
