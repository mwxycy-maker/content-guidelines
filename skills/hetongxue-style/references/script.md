# 口播稿

## 模式 A：创意制作（3–4 分钟，约 1100 字，4.9 字/秒）

| 段落 | 时间 | 做什么 |
|---|---|---|
| ① 身边的小麻烦 | 0:00–0:14 | 四五句交代问题（"每天中午很多同事点外卖，但园区里没有外卖柜……找外卖就像抽盲盒，要是下雨，大家就得吃冷饭了"） |
| ② 决定 | 0:14–0:30 | "为了解决上面所有问题，我决定给工作室做一个终极外卖柜。"之后 10–15 秒无口播，快剪制作过程 + 音乐 |
| ③ 成品亮相 | 0:30–0:40 | "这就是我们的外卖柜。"一句话一个亮点，先夸再自嘲（"晚上非常好看，但白天就有点拉"） |
| ④ 功能层层加码 | 0:40–2:10 | 每个功能都是"但我们的不一样"：贯通门、能制冷、按身高分配格子、机械臂、送餐机器人……每加一个功能就把场面推大一点，中间夹一个翻车笑点 |
| ⑤ 温度转折 | 2:10–2:40 | "但我总觉得这套系统缺了点什么……能不能再做点什么，帮助每天给我们送餐的外卖员呢？" |
| ⑥ 高潮彩蛋 | 2:40–3:30 | 回收开头埋的伏笔（"还记得我说过这个外卖柜会跳舞吗？"），纯音乐灯光秀 |
| ⑦ 合作口播 | 最后 20 秒 | 感谢 + 产品卖点，配三维追踪的大字参数 |

## 模式 B：体验长片（20+ 分钟，约 8000 字，6.2 字/秒）

| 段落 | 占比 | 做什么 |
|---|---|---|
| ① 一句话总结 + 最大看点 | 前 10 秒 | "iPhone 18 Pro 终于来了，它有……还有……但以上所有特性加起来，都比不过：能折。" |
| ② 快速说三个小点 | 1–2 分钟 | 先满足好奇心，"这里快速说三个小点：首先……第二……第三……"，再承诺"后面我们会做视频单聊" |
| ③ 宣告形式 | 1 句 | "不过不要走开……而且从现在开始，这期视频会很大胆。"→ 进入一镜到底 |
| ④ 逐项体验 | 60–70% | 外观 → 屏幕 → 影像 → 续航 → 存储 → 系统。每项：现象 → 原理（用实景演示讲透，如拉来一只羊驼讲景深） → 实测 → 一句个人评价 |
| ⑤ 发现问题 | 1 段 | "说到这里就是今年 iPhone 的问题之一了"，搭测试场景复现，给出自己的解决办法（3D 打印遮光罩并开源模型） |
| ⑥ 回顾与感慨 | 2–3 分钟 | 从产品拉到时代：线性的预期 vs 爆炸的世界；交代一镜到底的难处和用意 |
| ⑦ 结尾 | 30 秒 | 霓虹演播间里道谢、抽奖信息、"非常感谢，再见朋友们" |

## 语言质感
- **短促、清楚、带节奏的判断句**："妙。""早该这样了。""效果是真不错。"
- **自嘲和冷幽默放在句尾**，不停顿等笑："再多 1g 就不能起飞了""工作人员看我的眼神已经有点怪了""在朋友圈发截图能让人知道你换了新 iPhone"。
- **原理讲解用身边的比喻**："屏下摄像头就像隔着纱窗拍照""这个过程相当于……"
- **对观众说"你"，邀请参与**："你更喜欢哪段？欢迎打在公屏上""不知道大家更喜欢哪个"。
- **结尾抒情**要具体到个人感受，用"有时候我真的觉得……"开头，不喊口号。
