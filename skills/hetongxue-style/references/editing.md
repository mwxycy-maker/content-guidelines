## 模式 A：创意制作
- 全程快：25–39 刀/分钟，越往后越快（高潮灯光秀段 39 刀）。
- 制作过程用"蒙太奇快剪 + 无口播 + 音乐"，0.2–0.8 s 一刀，切在音乐节拍上。
- 每个功能介绍：一句口播配 2–4 个镜头（远景交代 → 特写细节 → 标注出现）。
- 笑点：说完立刻硬切到翻车画面（机械臂没接住、垃圾桶倒了），不加音效提示也行，靠反差。
- 高潮灯光秀：20–25 秒纯音乐，每个重拍切一个角度或一次灯光变化。

## 模式 B：体验长片
- 开头 2 分钟正常剪（约 20 刀/分钟），快速交代看点。
- 宣告"大胆"之后进入**一镜到底**：摄影机跟着主持人从一个布景走到下一个布景，用这些方法在不切镜的前提下换内容：
  - 走过遮挡物（墙、柱子、画框）时完成场景切换（实际可藏剪辑点）；
  - 镜头推近手机屏幕 → 屏幕内容填满画面 → 再拉出到新场景；
  - UI 卡片和三维文字在空间里出现、消失，承担"切镜"的信息变化。
- 一镜到底期间每分钟 0–3 个可见切点，单镜 25–180 秒。
- 结尾回顾段恢复剪辑（约 20 刀/分钟），用过去的老照片、老设备画面配回忆。
- 视频里坦白藏了剪辑点（"中间也有很多剪辑点，只能说是伪一镜到底"），反而增加真诚感。

## 通用
- 转场以硬切和"穿过物体"的匹配转场为主；不用叠化。
- 句间气口剪干净，但抒情段允许 0.5–1 秒的停顿让音乐呼吸。
