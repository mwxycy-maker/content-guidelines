# 交付前检查

## 共同
- [ ] 有一个让人记住的"形式"（真的造出来 / 一镜到底 / 特别的实验）
- [ ] 至少 3 处三维追踪标注，主字 + 副字，带霓虹发光
- [ ] 至少 1 个为讲清楚原理而专门搭的实景
- [ ] 句尾自嘲/冷幽默 3 处以上
- [ ] 有一段纯音乐高潮展示，剪辑卡在节拍上
- [ ] 结尾落到个人与时代的感慨，在霓虹演播间道谢
- [ ] 片尾 Credits + BGM 列表
- [ ] 成片 -16 LUFS，LRA 5–7 LU；口播段音乐比人声低约 20 dB
- [ ] 右上角常驻角标；字幕白色无底框

## 模式 A（创意制作）
- [ ] 3–4 分钟，平均镜头约 1.9 s，25–39 刀/分钟
- [ ] 开头 15 秒内交代麻烦，"我决定做一个……"
- [ ] 功能层层加码，有温度转折（为别人做点什么）
- [ ] 回收开头埋的伏笔

## 模式 B（体验长片）
- [ ] 前 10 秒一句话总结 + 最大看点
- [ ] "快速说三个小点"满足好奇
- [ ] 一镜到底段每分钟 0–3 个可见切点，用遮挡和屏幕穿越换场
- [ ] 指出产品的一个问题并给出自己的解决方案
- [ ] 视频里坦白拍摄的难处
