# 三维标注与包装动效

缓动：标注入场 `power3.out` 0.3 s；霓虹字用"闪烁点亮"（opacity 0→1→0.6→1，0.25 s，确定性序列）；不用弹跳。

### HT1 跟随物体的三维标签
- 需要先对实拍素材做摄像机/平面追踪（AE、Blender、Mocha）；在 HyperFrames 里可以用 `hyperframes-keyframes` 按逐帧坐标关键帧贴合。
- 主字：粗黑体 72–110px，白色 + 彩色外发光（青、品红、黄 三色错位 2–4px，做 RGB 分离）；副字：同色 24–30px，主字下方。
- 入场：主字从 6px 模糊 + 透明 0.3 s 变清晰，副字晚 0.1 s；离场跟着镜头离开画面，不做淡出。

### HT2 地面/物体上的大参数
- 超大斜体数字 + 单位（"35000Pa 吸力""最低 7.95cm"），透视贴在地面或机身侧面，白色或亮色，带轻微光晕。

### HT3 空间里的 UI 卡片
- 手机 UI 截图做成半透明圆角卡片（背景模糊 + 20% 白色 + 1px 白描边），浮在主持人身边或场景中，带一点景深。
- 数值变化（光圈 F1.8 → F4）在卡片里实时滚动。

### HT4 圆形倒计时
- 左上角 56px 圆环 + 中心数字（"18s"），圆环按时间扫描减少；配合演示段落。

### HT5 画框样张对比
- 两张照片放进金色画框，挂在布景墙上（实拍或合成），左下角白色小字写参数（"F4""F1.48"）。

### HT6 屏幕穿越转场
- 镜头推近手机/显示器屏幕 → 屏幕内容放大到满屏 → 成为下一段画面。0.6–1.0 s，`power2.inOut`。

### HT7 MacBook 框转场
- 画面外圈出现一个笔记本屏幕的黑色边框（带刘海），新画面在边框内展开，再把边框推出画面。

### HT8 片尾 Credits
- 黑底，左栏"Credits:"右栏"BGM:"，霓虹蓝紫描边字（外发光），列表白色小字；底部一行红色提示。整体 4–6 秒静止。

### HT9 霓虹演播间收尾
- 实拍为主：发光的字母标志、暖色球灯、架子上的霓虹小图标。可后期加轻微光晕增强。
