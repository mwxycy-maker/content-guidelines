# 何同学风格 Skill

从两期样片提炼：《我们做了个神奇外卖柜...》《【何同学】一镜到底。iPhone 18 Pro首发体验》。数值是实测。

一句话概括：**把科技当成可以亲手摆弄的玩具和可以感怀的时代，用花大力气搭的实景、贴在实物上的三维文字和一个出人意料的形式（一镜到底、真的造出来）讲产品，最后落到一句关于人和时代的感慨**。

这个风格有两种模式，先选一种：

| 模式 | 样片 | 适合 | 节奏 |
|---|---|---|---|
| **A. 创意制作（快剪）** | 外卖柜 | 自己动手做一个东西、解决一个身边的小问题 | 3–4 分钟，平均镜头 1.9 s，25–39 刀/分钟 |
| **B. 体验长片（长镜头）** | iPhone 18 Pro | 新品体验、深度测评 | 20+ 分钟，开头和结尾正常剪，中段一镜到底（最长单镜 177 s，多个分钟 0 刀） |

## 使用流程

1. 选模式，写稿 → `references/script.md`
2. 画面、布景与拍摄 → `references/visual.md`
3. 剪辑节奏（两种模式分开写）→ `references/editing.md`
4. 三维标注与包装动效 → `references/motion.md`
5. 声音 → `references/audio.md`
6. 交付前对照 `references/checklist.md`

用 HyperFrames 做标注和包装时，先读 `hyperframes`、`hyperframes-animation`、`hyperframes-keyframes` skill。

## 核心规格速查

| 项目 | 实测/规格 |
|---|---|
| 画幅 | 1920×1080，29.97 fps |
| 语速 | 创意制作 4.9 字/秒（留给画面和音乐）；体验长片 6.2 字/秒 |
| 平均镜头长 | A 1.89 s（中位数 1.44）；B 9.45 s（中位数 1.84，长镜头拉高均值） |
| 积分响度 | -15.6 / -16.0 LUFS |
| LRA | 5.4 / 6.8 LU（三个账号里动态最大：有纯音乐段、有安静的感慨段） |
| 音乐床 | 比人声低约 19–21 dB；高潮段音乐单独露出 |
| 字幕 | 白色中等粗细，约 1080p 下 32–36px，底部居中，无底框 |
| 角标 | 右上角常驻"老师好我叫何同学 + bilibili"小白字（换成自己的） |

## 不可省略的风格签名

- **形式本身就是选题**：真的造一个外卖柜、真的一镜到底拍完。在视频里交代为什么这样做、有多难（"折腾了很久，错了无数次……这是我们在 AI 时代的一点小任性"）。
- **贴在实物上的三维文字**：功能说明直接贴在物体旁边，跟随镜头运动（追踪），常用霓虹发光、彩虹色散的粗体字（"舵机 / 控制外侧柜门"），偶尔夹一个 emoji。
- **实景搭建 + 合成 UI**：为讲一个功能专门搭一个场景（圣诞树点光源场景、圆形聚光灯舞台、画框里放对比样张），相机 UI 和参数面板以半透明卡片浮在空间里。
- **主持人在场景里走动讲解**，镜头跟着他穿过一个个布景（长片模式）；创意模式里主持人更多是"做事的人"，不是坐着讲的人。
- **一段纯音乐的高潮展示**：外卖柜的灯光秀（约 24 秒无口播）、手机多米诺。
- **把幽默放在一句话的尾巴上**："再多 1g 就不能起飞了""未成年人不建议购买""工伤，这是工伤"。
- **结尾抒情**：从产品退到个人和时代（"有时候我真的觉得，跟上这个时代很累……我真的很怀念那个能把未来握在手里的时代"），然后在黑色霓虹灯演播间（发光的字母标志）里正式道谢，最后霓虹风格的 Credits + BGM 列表。

## 换成你自己的品牌

保留形式感、三维标注、实景搭建和抒情结尾的结构。频道名、霓虹灯字母标志、角标、主持人、合作品牌换成你自己的。
