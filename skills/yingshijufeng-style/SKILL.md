# 影视飓风风格 Skill

从两期样片提炼：《黑边=电影感？被观众们忽略的电影画幅，是如何讲故事的？》《影视飓风将停止制作25帧视频》。数值是实测。

一句话概括：**一个专业团队把一个影像技术问题讲透，主持人在精致布景里像朋友一样聊天，每个概念都配一段自己拍的高质感实拍或一段干净的说明动画**。和纯素材拼贴的科普不同，它的辨识度来自**画面本身的质感**：浅景深、讲究的布光、电影级调色。

## 使用流程

1. 口播稿 → `references/script.md`
2. 画面与分镜 → `references/visual.md`
3. 剪辑节奏 → `references/editing.md`
4. 动效与包装 → `references/motion.md`
5. 声音 → `references/audio.md`
6. 交付前对照 `references/checklist.md`

用 HyperFrames 做包装时，先读 `hyperframes` 和 `hyperframes-animation` skill。

## 核心规格速查

| 项目 | 实测/规格 |
|---|---|
| 时长 | 10.5–11.6 分钟 |
| 画幅 | 一期 1920×960（2:1，频道自定标准），一期 16:9。**默认用 2:1**，横屏手机黑边最少 |
| 帧率 | 新标准 29.97 / 59.94（频道明确宣布弃用 25/50） |
| 语速 | 6.1–6.3 字/秒（约 370 字/分钟），总字数约 3900–4150 |
| 平均镜头长 | 3.0 s / 4.7 s |
| 镜头长中位数 | 2.2 s / 3.2 s（两期 P10 都在 0.9–1.5 s，几乎没有一闪而过的快切） |
| 切速 | 稳定在 10–25 刀/分钟，峰值 31–33，节奏均匀 |
| 积分响度 | -16.1 / -16.3 LUFS，LRA 3.3–3.4 LU（很平） |
| 音乐床 | 全程铺底，比人声低约 18–19 dB |
| 字幕 | 白色细字、无底框、底部居中、字号偏小（约 1080p 下 30–34px），单行 |
| 角标 | 无常驻频道角标；引用素材时左上角出红色闪电"素材来源"标签 |

## 不可省略的风格签名

- **主持人布景是"精致的家"**：浅色北欧风书架客厅（自然窗光、白色柜子、绿植），或深蓝色调演播间（百叶窗、沙发、暖色台灯、机车模型）。主持人坐着或站着，穿浅灰卫衣，手势丰富。两个机位：中景 + 近景。
- **讲到数字时，数字直接以超大粗斜体白字弹在主持人身边**（"59.94""29.97""2"），和人同框，不另开画面。
- **一切演示都是团队实拍**：同事扮演"用户"在沙发上刷手机、俯拍桌面上硬盘被手推开、相机菜单特写、剪辑师在调色台前。实拍镜头都是浅景深、柔和侧光、带一点氛围烟雾感。
- **引用电影/他人素材**：左上角红色闪电图标 +"素材来源"+《片名》两行小字；左下角红点 + 斜体白字标注技术参数（如"2.35:1"），像录像机的 REC 读数。
- **原理讲解用干净的白底 UI 动画**：浅灰底、深色代码窗卡片（带 macOS 三色圆点）、紫色高亮行、对话气泡、小球运动演示。
- **开头要么是 7 秒纯音乐素材蒙太奇**（画幅期：电影片段 + 尺寸标注线），**要么是主持人一句话直接抛出决定/新闻**（帧率期："影视飓风的视频帧率将在近期从……变成……"）。
- **结尾**："好，以上就是本期节目的全部内容……点赞、投币、收藏、转发……给我们点个大的关注……我们下次再见"，有时在感谢之后补一个"哦对了"彩蛋段落。

## 换成你自己的品牌

保留结构、节奏、画面质感和包装语法，把频道名、主持人、布景、"素材来源"标签的 logo 换成你自己的。
