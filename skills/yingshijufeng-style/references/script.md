# 口播稿

## 量
- 3900–4150 字，6.1–6.3 字/秒，按 **370 字 ≈ 1 分钟** 估时长。
- 句子偏长，一句常带两三个分句，读起来像聊天，不像念稿。

## 结构（以 11 分钟为例）

| 段落 | 时间 | 做什么 |
|---|---|---|
| ① 钩子 | 0:00–0:40 | 两种开法任选：A. 纯音乐蒙太奇 5–8 秒后提问（"你是否有注意过画面的尺寸？有时候是这样的，有时候又是这样的"）；B. 主持人直接宣布一个与观众相关的决定或冲突（"我们的视频帧率将从……变成……这几年我们内部发生过多少次激烈的争吵"） |
| ② 问题清单 | 0:40–1:10 | 连抛 3–4 个观众会问的问题（"那标准这么多，为什么？我做视频该选哪种？真的这样才有电影感吗？"），然后承诺"希望接下来的内容能帮你彻底弄明白" |
| ③ 历史溯源 | 1:10–5:00 | 按年份讲来历（爱迪生、有声电影、电视普及、宽银幕竞赛），每个阶段一个技术原因 + 一个人物/公司 |
| ④ 回到实践 | 5:00–7:00 | "那问题是……"，把历史落到今天的创作者：该怎么选、自己频道怎么选、为什么 |
| ⑤ 延伸/新趋势 | 7:00–9:30 | 手机、竖屏、流媒体、行业新动向，引一个调查数据 |
| ⑥ 创作观点 | 9:30–11:00 | 用 3–5 部电影作案例（韦斯·安德森、贾樟柯……）说明"技术是为故事服务的"，收在一句创作观上（"画幅说白了就是你给自己设定的画布大小，你想在上面画什么、怎么画，才是最重要的"） |
| ⑦ 结尾 | 最后 15 秒 | 固定话术 + 可选"哦对了"彩蛋 |

## 语言质感
- **第一人称复数 + 团队视角**："我们研究过""我们内部""我们自己频道的视频""我们专门做了一整套遮幅送给大家"。把团队的真实决策和试错讲出来，是可信度的来源。
- **口语化吐槽**："不愧是你爱迪生，又当运动员又当裁判""这什么玩意啊""这太抽象了""你被背刺了""这个世界上怎么可以有这么草台班子的事情"。每 40–60 秒一处。
- **把原理算给你看**："每 0.2 秒会播放 5 帧……屏幕需要放 12 张……12 不是 5 的整数倍"，配动画一步步算。
- **和观众互动提问**："你觉得你会更喜欢变形宽银幕吗？""你们是习惯横屏还是竖屏看视频？对吧？"
- **观点有立场但讲理由**："我个人感觉 4:3 还是很有电影感，我特别喜欢这个画幅。"
- **给观众带走的东西**：遮幅素材包、模型文件、设置建议，结尾前提一句。
- 固定结尾：
  > 好，以上就是本期节目的全部内容。如果对你有帮助的话，也欢迎点赞、投币、收藏、转发，这会有非常大的帮助。给我们点个大的关注，那么我们下次再见。
