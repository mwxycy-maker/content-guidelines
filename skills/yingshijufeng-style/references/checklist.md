# 交付前检查

- [ ] 开头 40 秒内：蒙太奇或一句话抛出冲突，再连抛 3–4 个问题
- [ ] 有"我们团队怎么决定/怎么试的"段落
- [ ] 原理有一步步算给观众看的动画
- [ ] 每个抽象说法都配了团队实拍镜头，实拍是浅景深、讲究布光
- [ ] 引用片段都带左上"素材来源"标签，技术参数用左下红点读数
- [ ] 主持人讲数字时，数字直接弹在身边
- [ ] 结尾落到创作观，固定话术完整
- [ ] 平均镜头长 3–5 s，每分钟 10–25 刀，几乎没有 <0.8 s 的闪切
- [ ] 音乐全程铺底，比人声低 18–20 dB；成片 -16 LUFS，LRA 3–4 LU
- [ ] 画幅 2:1（或 16:9），帧率 29.97/59.94
- [ ] 字幕白色细字无底框
