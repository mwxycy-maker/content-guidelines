# 动效与包装

缓动：入场 `power3.out` 0.25–0.4 s，数字弹出用 `back.out(1.4)` 0.2 s（轻微回弹），其他不用弹跳。

### Y1 主持人身边的大数字
- 超大粗斜体白字（如 Montserrat/Oswald Black Italic 或思源黑体 Heavy 加 12° 斜切），150–200px，放在主持人头部左右的空处。
- 入场：scale 0.6→1，opacity 0→1，0.2 s；两个数字对比时左右各一个，错开 0.15 s。
- 可做"数字替换"：先出"50"，下一句变成"59.94"（旧数字 0.1 s 淡出 + 新数字弹入），表达变化。

### Y2 素材来源标签
- 左上角，距边 24px：红色闪电图标（约 28px）+ "素材来源"白色粗体 18px + 第二行《片名》14px，右侧一组小斜线装饰。
- 随片段一起硬切出现，不做动画。

### Y3 画幅读数
- 左下角：红点（10px，`#E5262B`）+ 斜体白字"2.35:1"约 24px，像 REC 读数。

### Y4 画幅尺寸标注
- 画框外画白色 1px 标注线，两端箭头，中间写数值（"1.78""2.39"），竖向同样标"1"。
- 画框从一个比例形变到另一个比例：遮幅黑边 0.6 s `power2.inOut` 推入或拉开，标注数值同步滚动。

### Y5 胶片带 3D 动画
- 深蓝紫背景 + 模糊光球漂浮（极慢，4–6 s 一个周期，用确定性的 sin 运动）。
- 紫色片基 + 黑色齿孔的胶片带横穿画面，片格里放画面；镜头沿胶片推进或绕转。
- 数值标签放在深蓝圆角牌上（"1.85:1"），带外发光。

### Y6 白底原理卡片
- 浅灰底 + 淡网格；深色圆角代码窗卡片从下方 20px 淡入。
- 关键行背景变紫色（`#7B5CFF` 一类）0.3 s；旁边白色对话气泡弹出写观众疑问，带紫色头像圆点。
- 计算结果用红色标出错误位（"360÷25=14.4"里的小数部分）。

### Y7 评论卡片堆叠
- 4–6 张深色评论卡片，从画面外依次飞入叠放，每张随机但确定的旋转 -8°~8°，错开 0.08 s。

### Y8 分屏对比
- 上下或左右等分，每格左侧灰色小字标签；两格内容同步播放。

### 片头片尾
- 无独立片头 sting；开头的素材蒙太奇就是片头，结尾话术后直接黑场结束。
