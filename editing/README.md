# 跨风格剪辑规则

本目录是视频制作的通用剪辑规范，适用于口播、知识讲解、评测和教程视频。**当期用户明确要求 → 本目录通用剪辑规则 → 风格 Skill 参考**，依次执行。这里决定视频基调、制作流程和硬性指标；风格 Skill 只提供可借鉴的表现方式。

## 同时使用通用规则和风格 Skill

| 发生差异的地方 | 执行方式 |
|---|---|
| 当前视频的明确要求 | 优先执行；修改前核对实际素材与时间线 |
| 可编辑预览、音画同步、停顿、字幕、BGM、混音和导出 | 按本目录规则执行；风格 Skill 的不同数值或流程不覆盖它 |
| 选定风格里的字体、配色、镜头语法和叙事例子 | 只作参考，符合通用剪辑规则才采用；不混用多个账号的风格 |
| 旧项目中的时间点、歌曲、配色、模型名单 | 只当案例参考，不自动复制到新视频 |

例如，本目录要求字幕按语义断句并在手机上可读，通常一行约 8–16 字；风格样片出现 6–14 字时，只能在满足这两条要求下借鉴。本目录的整片 -14 LUFS 与真峰值 -1 dBTP 是当前通用交付目标；风格样片的 -15 或 -16 LUFS 是观察值，不改写目标。BGM 按实际话题或章节换曲，30–45 秒只是审片交付分段，不是强制换歌点。超过约 0.5 秒的无用空停顿要处理，有意的情绪停顿另行安排。

## 从哪里开始

1. [工作流程](01-工作流程.md)：对齐素材、定交付、建立时间线，先交前段确认方向。
2. [口播与字幕](02-口播与字幕.md)：转写校对、剪长停顿、整理显示字幕，保证音画同轴。
3. [画面与动效](03-画面与动效.md)：逐句配画面、处理素材、安排动效与构图。
4. [声音与配乐](04-声音与配乐.md)：按段选歌、设计换歌、匹配音效、混音。
5. [审片与交付](05-审片与交付.md)：逐段检查、浏览器预览和明确要求后的导出。

## 适用范围

- 固定配色、具体歌曲起点、某期模型名单和一次性的内容限制不属于通用剪辑规则；按当期任务确定。
- 规则写在本目录，可编辑网页预览引擎在 [`web-player/`](../web-player/README.md)。每期的台词、素材、音乐、音效和工程留在当期视频项目，不进入规范仓库。
- 工具名称和参数是可选的实现方式。即使本机没有对应工具，也要完成规则要求的剪辑、试听和审片；不能把外部仓库当作本规范的运行前提。

## 每段最短检查

- 口播与字幕按实际说出的内容对齐；长空停顿已压缩，有用的停顿已明确安排。
- 口播点到什么，画面才出现什么；素材文字、人物和字幕在手机上能看清。
- 音效有对应动作，换段时 BGM 有设计，口播始终清楚。
- 静帧和浏览器播放均审过；默认交可编辑工程及预览，明确要求后再导出视频。
