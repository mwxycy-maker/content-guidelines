# 跨风格剪辑规则

本目录把两个仓库中可以跨项目复用的剪辑要求汇总为一套工作顺序。适用于口播、知识讲解、评测和教程视频。当前视频的明确要求优先；此前 [jianjiguize](https://github.com/mwxycy-maker/jianjiguize) 的个人规则优先于 [video-workbench](https://github.com/mwxycy-maker/video-workbench) 的旧工作台规则。风格选择由本仓库的 `skills/` 决定。

## 从哪里开始

1. [工作流程](01-工作流程.md)：对齐素材、定交付、建立时间线，先交前段确认方向。
2. [口播与字幕](02-口播与字幕.md)：转写校对、剪长停顿、整理显示字幕，保证音画同轴。
3. [画面与动效](03-画面与动效.md)：逐句配画面、处理素材、安排动效与构图。
4. [声音与配乐](04-声音与配乐.md)：按段选歌、设计换歌、匹配音效、混音。
5. [审片与交付](05-审片与交付.md)：逐段检查、浏览器预览和明确要求后的导出。

- 没有复制 `video-workbench/风格库`、参考视频、字体、音乐、音效或工具代码。网页预览引擎已单独放在本仓库的 [`web-player/`](../web-player/README.md)。
- 固定配色、具体歌曲时间点、某期模型名单等属于案例配置，不升级为所有视频的规则。旧工作台的“画面不出现中国模型”与后续三模型 PK 案例冲突，因此应视为当期内容限制，由当期要求决定。

## 每段最短检查

- 口播与字幕按实际说出的内容对齐；长空停顿已压缩，有用的停顿已明确安排。
- 口播点到什么，画面才出现什么；素材文字、人物和字幕在手机上能看清。
- 音效有对应动作，换段时 BGM 有设计，口播始终清楚。
- 静帧和浏览器播放均审过；默认交可编辑工程及预览，明确要求后再导出视频。
