# 04 BGM、音效与混音

## 按段落选歌

- 当期开头有指定歌曲时先用指定曲。后续按段落情绪换歌；一首歌只支撑一个话题，画面切到新段落时 BGM 跟着设计换曲。有人出镜时避免铺空灵氛围乐；有人声的歌曲不要垫在口播下面，应选无人声的前奏或间奏。
- 换歌按“上一首怎样停 → 用台词、画面或音效接住注意力 → 下一首从哪个强拍进”设计。普通段尾可用短混响尾巴；反转或笑点可刮停、留空；重击前可短暂压低音乐。下一首从强拍或 drop 进，实际起音点要听音频或用节拍工具核对，不能只看粗粒度响度表。
- 口播停顿处可把音乐抬起来配重击；大标题和重击同帧。换歌手法要与内容相称，不必每次堆 riser、刮停和留白。配乐事件应挂在时间线锚点，口播调整后能一同更新。

## 音效

1. 一个音效对应一个画面动作；没有动作就不加。大标题、撞击、卡片入场等要把声音落点对齐动作；教程录屏默认不添加鼠标点击声。
2. 按阿亮确认的顺序挑：先在 [earshot](https://github.com/Leonxlnx/earshot) 试听最贴切的音效；没有合适的，再到 [Openverse 音频搜索](https://openverse.org/search/audio) 选 Freesound 来源；哔声等简单信号音可自行合成。下载的素材优先 CC0；CC BY 要按许可署名，并在当期记录文件名、作者、许可和链接。
3. `start` 对齐音效开头，`end` 对齐收束，`peak` 对齐最响处；whoosh、riser 和重击要按实际波形选对齐点。连续相同动作保持音色一致，可换不同 take；同一时刻通常不超过两层，逐段试听有无抢口播或过量。

## 混音交付指标

以下数值来自 `jianjiguize` 的已完成视频，也是本仓库当前的通用交付目标。风格 Skill 中的响度属于样片观察值，不覆盖此处目标；当期用户明确指定其他交付规格时按当期要求执行。正式交付还要用听感和测量结果验收。

| 项目 | 指标与做法 |
|---|---|
| 人声 | 约 -16 LUFS；剪点两端约 12 ms 淡入淡出 |
| 音乐 | 每首按参考段定响度，常在 -17 至 -21 LUFS；中高频密集的歌再压低 |
| 口播时音乐 | 自动压低约 11 dB；起声约 60 ms、释放约 350 ms；口播停顿处自然抬升 |
| 整片 | 目标 -14 LUFS、真峰值不高于 -1 dBTP；两遍测量与归一化 |
| 画面素材原声 | 说话时画面视频静音，声音统一走混音音轨，避免叠播 |

改口播时间线、配乐表或音效表后，必须重混并确认预览使用的是新音轨；逐段听人声、音乐和音效的相对响度。
